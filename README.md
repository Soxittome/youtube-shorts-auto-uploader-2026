Automatically uploads pre-rendered videos to YouTube Shorts on a schedule. Manages titles, descriptions, hashtags and thumbnail for each video from a CSV list.

## Features

- Schedule unlimited Shorts uploads
- Auto-fills title, description and hashtags from CSV
- Custom thumbnail per video
- Handles multiple YouTube accounts
- Retry on upload failure
- Works 24/7 in background

## FAQ

**Do I need to be logged in while it runs?**  
After the first auth, the tool stores OAuth tokens and works fully unattended.

**Can it manage multiple channels?**  
Yes — add accounts via the Settings panel and assign videos to each.

## Requirements

- Windows 10 / 11 (64-bit)
- Google account connected
- Videos ready as MP4
